# Guide simple : Plan éditorial avec l'IA

## La pipeline en 5 étapes

```
1. IDÉES          2. PLAN            3. RÉDACTION       4. VALIDATION      5. PUBLICATION
Notes vocales →   Google Sheets →    Claude écrit   →   Vous relisez   →   N8N publie
appels clients    (calendrier)       les posts          statut "approuvé"  automatiquement
```

### Étape 1 — Collecter la matière (1h/semaine)
- Notez les questions réelles de vos clients (appels, DM, commentaires).
- Copiez 3–5 transcriptions de posts/vidéos de concurrents qui marchent.

### Étape 2 — Le calendrier Google Sheets
Créez un Sheet avec ces colonnes :

| Date (AAAA-MM-JJ) | Heure | Format | Contenu | Statut |
|---|---|---|---|---|
| 2026-06-16 | 08:00 | texte | ... | en attente |

- Rythme : **3–4 posts/semaine** (ex. mardi + jeudi).
- Séquence qui se répète : **Attirer → Engager → Vendre**.

### Étape 3 — Rédiger avec Claude
Prompt type :
> « Voici 5 de mes contenus qui ont bien marché : [coller]. Analyse mon style
> (ton, accroches, rythme). Puis transforme ces notes brutes : [coller]
> en 10 posts LinkedIn dans ce style, en suivant la séquence
> Attirer / Engager / Vendre. »

### Étape 4 — Valider
Relisez chaque post → passez le statut à **"approuvé"**. Jamais de publication sans validation humaine.

### Étape 5 — Automatiser (optionnel, plus tard)
N8N lit le Sheet chaque matin → publie les posts "approuvés" du jour → Claude Haiku génère le visuel.
